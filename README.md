# ═══ مسلم AI — خادم الإنتاج الآمن ═══

## التشغيل السريع
```bash
npm install
cp .env.example .env        # املأ LLM_API_KEY و ADMIN_CODE
npm start                   # http://localhost:3000
```

## بنية المجلد
```
muslim-ai-server/
├── server.js          # الخادم الآمن (القلب النابض)
├── package.json
├── .env.example       # انسخه إلى .env (ممنوع رفعه لـ GitHub)
├── .gitignore
├── data/              # يُنشأ تلقائياً — مصادر لوحة الأدمن (sources.json)
└── public/            # ملفات الفرونت إند الستة
    ├── Muslim.html    # (معدّل: المصادر الجديدة + الإحالة للمفتيين)
    ├── quraan.html  admin.html  library.html  community.html  setting.html
```

## الأمان المنفَّذ
| الحماية | التنفيذ |
|---|---|
| المفتاح السري | env فقط، لا يصل للمتصفح أبداً |
| Rate Limiting | 15 رسالة/دقيقة/IP + حدود منفصلة للأدمن |
| حد حجم الطلب | 256KB لكل طلب JSON |
| حقن الأوامر | كشف Prompt Injection ورفض الطلب |
| الحالات المحظورة | طلاق/مواريث/قضاء/تكفير/انتحار/سحر/إجهاض → إحالة فورية للمفتيين **بدون وصول للنموذج** (كشف مزدوج: عميل + سيرفر) |
| الأدمن | SHA-256 + timing-safe + جلسات موقّعة (ساعتان) |
| المصادر | إجابات حصرية من مصادر لوحة الأدمن — وإلا "لا تتوفر إجابة موثقة لهذا السؤال" |
| رؤوس أمان | nosniff / DENY frame / COOP / no-referrer |

## الإحالة للمفتيين (Guardrails)
عند سؤال عن أي فئة محظورة:
1. يظهر: "عذراً، هذه المسألة تتطلب دراسة شخصية وسماع التفاصيل من عالم مختص..."
2. تُفتح تلقائياً نافذة أرقام المفتيين
3. داخل النافذة تنبيه: التطبيق لا ينتمي رسمياً لهذه الجهات
